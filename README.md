This Inventory Management System prototype exercises the basic functions in Python. The system is created for a small retail client to manage their inventory system. This interprets how to do input handling, calculations, and data management. 
The system has the following features;
  - Store inventory items.
  - Add items to the directory. Quantities and prices of each item.
  - Auto generate the item id.
  - Calculate the total value of each inventory item.
  - Update item quantity and price
  - Display the inventory information
  - Check the item in the system.

How to use the programme.
- When you run the programme, it will prompt to input the item name. Then follows the item quantity and price.
- The item unique id will be generated that is start from 1000. The first item id will be 1000 and increase each item adding afterwards by one.
- The system will process the information and display the item name, quantity, item id and the total value.
- Then the system indicate to update the items as required.
- Enter the new quantity and price of the existing item.
- Will display the updated item details.
- Will check whether an item is in the system.
    
How to run the programme
- Download the code from the Repository.
- Open the project in the Visual Studio Code
- Run the programme in Python 3.
- Enter the inventory information
